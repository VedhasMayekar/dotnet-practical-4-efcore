# pract5

Practical 5: Design Razor views and work with layouts and partial views.

- Shared layout page: `Views/Shared/_Layout.cshtml`
- Strongly typed student details view: `Views/Student/Details.cshtml`
- Reusable navbar and footer partials: `Views/Shared/_navbar.cshtml`, `_footer.cshtml`

Open `pract5.csproj` in Visual Studio 2026 with the .NET 8 SDK and run the project. The default page displays the student details.
